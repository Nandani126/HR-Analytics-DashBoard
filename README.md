## 📌 Project Overview

The **HR Analytics Dashboard** is an interactive Tableau project designed to analyze employee data and uncover meaningful workforce insights. The dashboard helps organizations understand employee attrition trends, workforce demographics, departmental performance, and job satisfaction metrics.

This project demonstrates the use of **data analytics and visualization techniques** to support better HR decision-making.

---

## 🚀 Key Features

✅ Employee Attrition Analysis  
✅ Department-wise Insights  
✅ Gender & Age Distribution Analysis  
✅ Job Satisfaction Metrics  
✅ Salary & Experience Insights  
✅ Interactive Filters & Visualizations  
✅ Professional Dashboard Design
